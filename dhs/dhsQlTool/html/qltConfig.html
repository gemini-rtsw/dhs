Configuring the Quick Look Tool

This window displays the configurable items and their current values, if they have one. These values can be edited. The items that can be configured are:
  • Data Server Address.
    The IP address, or machine name, of the machine where the Data Server is running.
  • Data Server Name.
    The identifier used by IMP that identifies the Data Server to be used by the Quick Look Tool.
Note that the values do not change until the "OK" button is selected.

Below the configurable items are three buttons. The actions taken by the buttons when they are selected are as follows:

Button Actions
Button Action
OK Changes the configuration information to the values entered. Also remove the configuration editor from the display.
Cancel Remove the configuration editor from the display without changing the configuration information.
