User-interface Controls

This page provides the details on how to manipulate the various widgets or components of the Quick Look Tool control panel. The topics discussed include:
  • Accessing Help Information
  • Manipulating Menubars and Menus
  • Manipulating Paned windows
  • Invoking Buttons
  • Text Entry
  • List Selection
  • Manipulating Scrollbars

Accessing Help Information

All help information is displayed in a Netscape browser; if no browser is running one will be started. See the Netscape help information on how to use the Netscape browser.

Help information is activated from menus on the control panel. Many of the pop up windows (dialogues) have help buttons. When these buttons are invoked the help information describing the window is displayed.

The control panel has little box at the bottom for displaying "short help" messages. Short help messages are brief descriptions of the various bits and pieces that make up the Quick Look controls. The message that is displayed describes the component under the cursor. To see the short help messages of a particular component move the cursor over the desired component. Note that windows that do not have a short help box display their messages in short help boxes on other windows.

Detailed help information describing a particular component of the Console can be accessed quickly with "context-sensitive" help. To display the help information of a particular component move the cursor over the component and press mouse button 3.

Manipulating Menubars and Menus

The control panel contains a menubar at the top of the window. To select a menu from the menubar move the cursor over the desired menu and press mouse button 1. Menus can also be activated from the keyboard,; by pressing the ALT key and the key of the underlined character in the menu's name. For example, to activate the "Dataset" menu press the ALT and D keys simultaneously.

When selected, the menu is displayed with a number of choices. One of these items can be chosen or the menu can be removed without selecting any items. To make the menu disappear press mouse button 1 when the cursor is not over the menu, or press the Escape key. To select one of the items either press mouse button 1 when the cursor is over the desired choice, or press the key of the underlined character. For example, to choose "Autocut" from the "Dataset" menu press the C key.

In addition the arrow keys can be used to navigate the menu and the menubar. The up and down arrow keys move through the choices on the menu and the left and right arrow keys move between the menus. Once the desired selection is highlighted press the "Return" key to choose the item.

A menu can also be "torn off"; removed from the menubar and is permanently displayed. This can be achieved by pressing mouse button 1, when the cursor is over the dashed-line that appears at the top of the menu. A "torn-off" menu can be controlled with the window controls provided by the X window manager. (See window manager documentation for more information). Note that a menu can be accessed from the menubar even though it is "torn-off".

Manipulating Paned windows

Paned windows are windows that have "panes", or sections. Between each pane there is a "sash" which can be used to change the relative sizes of the panes. On each sash there is a button. The sash can be moved by holding down mouse button 1 while moving the mouse. This will cause the sash to be "dragged". Release mouse button 1 once the sash has been moved into the desired position, at this point the sizes of the panes will be adjusted.

Invoking Buttons

Two types of buttons are used on the Quick Look Tool control panel: push and check.

Push Buttons

Push buttons, as their name suggests, when pushed cause an action to be initiated. Note that buttons whose text is gray in colour are not active, can not be invoked. Those that have black text are active.

Buttons appear at the bottom of pop up windows. To invoke a particular button move the cursor over the button and press mouse button 1.

Check Buttons

Check buttons appear on the "Dataset" menu. Each check button represents an item which can be turned off or on. Where check buttons appear more than one can be selected at any given time. If the check button is sunken it it turned on.

To select a check button position the cursor over the button and press mouse button 1. Pressing the space bar or Return key when the check button as the focus (is highlighted) will also select the check button.

Text Entry

On the Custom Stream Editor and the Configuration Editor there are places where text can be entered. Text can be entered in the sunken boxes, entry boxes, by typing when the box is selected. All normal printing characters are inserted where the insertion cursor is positioned.

Depending on the window manager configuration, the box can be selected by positioning the mouse over the box or by pressing mouse button 1 when the cursor is over the box. Note that the cursor should change to the "I" cursor when the box is selected.

To position the cursor at a given point in the text press mouse button 1 when the cursor is over the character just after the desired position. The left arrow and right arrow keys can also be used to move the cursor. To select a word "double-click" mouse button 1 and to select all of the text "triple-click" mouse button 1. On the other hand to select a given piece of the text position the cursor over the starting position hold mouse button 1 and move the cursor to the end of the piece, now release mouse button 1. Text can also be chosen by holding the shift key while moving the left arrow and right arrow keys. Note that if the mouse is "dragged" out of the box (left or right side) then the entry will automatically scroll to make more text visible, if there is more.

To insert the cursor at a given position without affecting the selection press mouse button 1 while holding down the Control key.

Other useful key controls include:

  • control and right arrow simultaneously moves the cursor to the right a word at a time.
  • control, shift, and right arrow simultaneously moves the cursor to the right a word at a time and "selects" text.
  • The home key moves the cursor to the beginning of the entry.
  • The home and shift key moves the cursor to the beginning of the entry, and selects the text.
  • The end key moves the cursor to the end of the entry.
  • The end and shift key moves the cursor to the end of the entry, and selects the text.
  • The delete or backspace key deletes the selection.
Further controls can be found in the Tcl/Tk entry man page, found in section "n" of the Tck/Tk unix man pages.

List Selection

Items can be selected from a list of items by pressing mouse button 1 when the cursor is over the desired item. Lists are are used to display the custom streams, known streams, streams selected, and the available frames.

Double Lists

A double list consists of two lists where the list items can be moved back and forth between the lists. Two controls buttons are used to move the items from one list to the other. A double list is used on the Quick Look Tool control panel to select streams. To move items first select the list item with mouse button 1. A group of list items can be selected by holding mouse button 1 while moving the cursor in the listbox. Release mouse button 1 once all of the desired items are highlighted. Once all of the items have been selected the press the arrow pointing towards the destination list.

Manipulating Scrollbars

In general scrollbars are displayed only when necessary, when the text goes beyond the boundaries of the window. Scrollbars can appear on the control panel, stream subscribe, and custom stream windows.

The scrollbars themselves can be operated with the mouse. Pressing mouse button 1 when the cursor is over one of the arrows causes the scrollbar to move in the direction of the arrow. If the mouse button is held down the movement is repeated.

Pressing mouse button 1 when the cursor is over the "trough" causes the list to be shifted by one page. If the cursor is above the slider then it moves up and if the cursor is below the slider it is moved down, for a vertical scrollbar. The trough is the area of the scrollbar that is between the arrows and the slider.

Pressing mouse button 1 when it is over the slider and dragging it causes the view to be dragged with the slider. The slider is the portion of the scrollbar which moves.

Pressing mouse button 2 when it is over the trough sets the view to correspond to the mouse position. Pressing mouse button 2 when it is over the arrows causes the same action as mouse button 1. If mouse button 2 is pressed in the display area, where lists are displayed, the view is dragged while the button is held down.

If the Control key is down when mouse button 1 is pressed over an arrow or the trough the view is adjusted to the very top or the very bottom.
