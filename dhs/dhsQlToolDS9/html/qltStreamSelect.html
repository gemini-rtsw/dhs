Stream Selection

This window contains a scrollable double list, two lists. The list on the left contains the streams that will not be displayed in the Quick Look tool while the list on the right contains the list that will be displayed. Between these two rows are two buttons.

To add a stream(s) to the list of streams that will be displayed select the desired stream(s) in the left hand list. Then select the button with the arrow that points to the right.

Similarly, to remove a stream(s) to the list of streams that are not displayed select the desired stream(s) in the right hand list. Then select the button with the arrow that points to the left.

Below the two lists are three buttons. The actions taken by the buttons when they are selected are as follows:

Button Actions
Button Action
OK Changes the list of streams to the "selected" ones and removes the stream selection window from the display.
Cancel Remove the stream selection window from the display without changing the list of selected streams..
Help Display this help information.

Note that the list of streams in the double list is dynamic and is retrieved from the Quick Look Server each time the window is displayed. (See the stream information for more details.)

Also note that no streams are selected automatically by the Quick Look Tool and if no streams are selected then all streams are displayed on the Quick Look Tool.
