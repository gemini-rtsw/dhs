Displaying a Dataset.

  1. selected the "Display Dataset" menu item on the "Dataset" menu which is available from the Quick Look Tool Control Panel. At this point a prompt dialogue will appear. This dialogue box is described below.
  2. Enter the desired dataset in the entry box on the dialogue box.
  3. Select the "OK" button at the bottom of the dialogue window.

Prompt Dialogue

The Dataset Display prompt dialogue will appear after step one is followed above. This dialogue is "modal", which means that all other windows are disabled while this window is viewable.

At the top of the window is a box where the desired dataset name is to be entered.

Below the box appears two buttons. The buttons and their actions are described in the table below.

Button Actions
Button Action
OK Sends the request for the specified dataset to the Quick Look Server, which requests the dataset from the Data Server. Also the prompt dialogue is removed from the display when this button is selected.
Cancel Does not send a request for the specified dataset but does removes the prompt dialogue window from the display.
