Quick Look Streams

The routing of data to Quick Look Tools is controlled by Quick Look Streams. Quick Look Streams are assigned to datasets when they are created, and subscribed to by the users of Quick Look Tools. Quick Look data is routed to all Quick Look Tools which have subscribed to at least one of the streams assigned to the data. Quick Look Tools subscribe to streams by selecting one of the streams known to the Quick Look Server or by adding streams to the custom stream list.

Quick Look Streams can be defined in four different but not mutually exclusive ways:

  • Streams can be defined in the Quick Look Server's configuration file (dhsQlServer.config) of the master Quick Look Server. These streams are always listed in one of the list boxes of the Subscribe Streams Window. This is the preferred way to define Quick Look Streams.

    As many streams as possible should be defined in the master Quick Look Server configuration file, since it is somewhat easier for the user of a Quick Look to subscribe to these streams than it is to subscribe to transient streams.

  • Streams can be defined when they are associated with a dataset. If the stream name has already been defined in the configuration file (dhsQlServer.config) of the master Quick Look Server, then this has no effect on the list of streams known to the Quick Look Server.

    If the stream name is not defined in the configuration file, then the stream name will be added to the list of streams known to the Quick Look Server, and will remain in the list of streams until the last of the data for the dataset is received. If any Quick Look Tool activates the stream selection window while data for the dataset is being received, the list of streams will include the streams defined for the dataset. This feature would be useful for an instrument like the guide camera, where one dataset could be used to send many frames to the Quick Look System over a long period of time.

  • Streams can be defined in the Quick Look Tool's configuration file (dhsQlt.config). These streams will only be visible to the Quick Look Tool in which they are defined. This feature can be used to subscribe to streams which are not defined in the master Quick Look Server configuration file, and where it is not practical to attempt to display the stream selection window while the data for the dataset is being received.

  • Streams can be defined in the Quick Look Tool's custom stream editor. Streams defined in this way will only be visible to the Quick Look Tool in which they are defined. This feature can be used to subscribe to streams which are not defined in the master Quick Look Server configuration file, and where it is not practical to attempt to display the stream selection window while the data for the dataset is being received.
