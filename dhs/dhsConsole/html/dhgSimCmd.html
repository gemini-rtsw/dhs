Simulation Command

This command sets the simulation level of DHS and its subsystems. Setting the simulation level for the entire DHS requires setting the simulation level of all the DHS subsystems. The simulation command itself will never be simulated.

The simulation level specifies whether or not the subsystem or DHS is to run in simulate mode. When running in simulate mode commands are not actually performed, but do appear as if they have. When not running in simulate mode all commands are performed. The Data Processing subsystem may or may not handle simulation as described.

Viewing the Simulation Level

The current simulation level can be obtained from the simulation level indicators.

The Simulation Level Command Window

The simulation level command window can be activated from the main window of the Console or from a subsystem window, as described below.

A separate simulation level window may be displayed for each subsystem. The title given on the window indicates which subsystem the window is associated with, or if it is associated with the entire DHS system. The simulation level command affects only the subsystem the window is associated with.

The Simulation windows have a fixed set of choices: NONE, VSM, FAST, and FULL, described on the simulation level indicator help page. The list of choices appears on the simulation level menu. The simulation level menu is displayed when the button beside the text "Selected Simulation Level" is selected. When one of the simulation levels on the menu is selected the menu will disappear, but the selected simulation level will now appear on the button. Note that the simulation level has not changed yet! It will change when the "OK" or "Apply" button is selected.

The current simulation level is displayed in a non-editable box beside the text "Current Debug Level:".

At the bottom of the window is a row of buttons; the actions taken by the buttons when they are selected are as follows:

Button Actions
Button Action
OK Sends a simulateLevel command to DHS, with the selected simulation level. Also removes the simulation level command window from the display.
Apply Sends a simulateLevel command to DHS, with the selected simulation level. The simulation level command window is NOT removed from the display.
Cancel Does not send a simulateLevel command to DHS, but removes the simulation level command window from the display.
Help Displays this help information.

Changing Overall DHS Simulation Level

  1. Display the Simulation Level Command Window:
    • From the "Commands" menu:
      Display the "Commands" menu and select "Simulate" from the menu
    • From the Toolbar:
      Below the status information is a row of buttons. Select "Simulation" from this row of buttons.
  2. Select the desired Simulation Level:
    1. Display the Choice List:
      Select the button beside the text "Selected Simulation Level"
    2. Select a simulation level from the pop up menu. After a choice is made the list of choices is removed from the display and the selected value is shown. The simulation level does not change until either the "OK" or the "Apply" button is selected.
  3. Select the appropriate button at the bottom of the window. The actions taken by each button are described above.

Changing Subsystem Simulation Levels

  1. Display the Subsystem Window:
    Select the desired subsystem's button on the main window of the Console
  2. Display the Simulation Level Command Window:
    • From the "Commands" menu:
      Display the "Commands" menu and select "Simulation" from the menu
    • From the Toolbar:
      Below the status information is a row of buttons. Select "Simulation" from this row of buttons.
  3. Select the desired Simulation Level:
    1. Display the Choice List:
      Select the button beside the text "Selected Simulation Level"
    2. Select a simulation level from the pop up menu. After a choice is made the list of choices is removed from the display and the selected value is shown. The simulation level does not change until either the "OK" or the "Apply" button is selected.
  4. Select the appropriate button at the bottom of the window. The actions taken by each button are described above.
