Retrieval Action

Retrieval is defined to be the action of fetching the files, from the DHS, that are needed in order to satisfy a media request.

Viewing Retrieval Information

There are three status records associated with retrieval. They are:
  • Retrieve Size.
    A positive integer number, which is the number of megabytes of data that can be retrieved.
  • Retrieve State.
    Indicates the current state of the retrieval action, expected values are given below.
  • Queue Size.
    The number of media units, CDs, of data that can be queued. Also could be defined as the amount of data that has been retrieved.
All three status records are displayed on the Storage Server's window and also on the Request window. The request window displays each of the status records in a non-editable box. The subsystem window uses a combination of text and colours to portray this information.

Obtaining Further information

Further information, describing the files ready for retrieval, can be obtained by pressing the "retrieval" information button on the Storage Server window. This will display the Storage Server's Action Information window. Similarly, the list of files that are ready for queuing (have been retrieved) can be obtained by pressing the "queue" information button.

Changing Retrieval Information

Retrieval information can not be changed directly. However, it does change when data is retrieved, data is queued, or when a queue action is undone.

Retrieval information can also change during a reset or an initialize command.

Expected Retrieve State Values

 The expected retrieve state values are listed in the table below. Given any particular state there is one or more states the action can move to. The state transition diagram below depicts the allowed moves (transitions).

Expected Retrieve State Values
Value Interpretation
IDLE No processing is currently being performed on the data to be retrieved.
REQUESTED A retrieval of data process is currently waiting to start.
IN-PROGRESS A retrieval of data process is currently running, data is being retrieved.
