Cancel Action Command

The Cancel action either stops an action that is currently being processed or cancels an action that is waiting for processing. Effectively, it removes an action from the Storage Server's action queue. The actions which can be cancelled are:
retrieve, queue, prepare, write, cleanup, and notify.

Initiating a Cancel Action Command

The Cancel Action Command can be initiated by pressing on the Storage Server's window for the desired media request. A number of detailed example of initiating a Cancel Action Command are given below. (Note: a stop button may be disabled, disallowing the cancel action for the time being.)

Shortly after the button has been pressed a dialogue window will "pop-up". The dialogue window asks the operator whether the desired action should be cancelled/stopped. Once the "yes" button on the dialogue is selected the command will be sent to the Storage Server for processing. There are two buttons on the dialogue window which are described below.

Once the Cancel Action command has been received by the Storage Server the Storage Server Window will be disabled until the Cancel Action command has been completely processed.

Button Actions
Button Action
OK Sends the stoRequestAction command to the Storage Server, with the appropriate values, for processing. Also removes the dialogue window from the display.
Cancel Does not send the stoRequestAction command, cancels it, and removes the dialogue window from the display.

Viewing Affected Status Information

Media request information will be altered as the result of a Cancel Request Action command. Only the action state will change for the associated media request and action. The specific media request information that is altered is described in detail where the retrieve, queue, prepare, write, cleanup, and notify actions are described. All media request status records are displayed on the Storage Server's window in "Request Overview" section. The information can also be found on the Request window for the affected request.

In addition to the media request information being altered the following items will change:

  • Action Queue. The action queue will shrink by one every time an action is requested.
  • Media Stage Directory List. A media staging directory may be unbooked when stopping a prepare action that is being processed.
  • Device List. A device may be unbooked when stopping a write action that is being processed.

Cancel Action Dialogue Window

 The Cancel Action Dialogue is displayed when the appropriate stop button on the Storage Server window is selected. This window is "modal", which means that all other windows are disabled while this window is viewable.

A prompt is displayed on the dialogue, which asks if the action should be cancelled (stopped). The prompt states the name and media identifier of the media request, to help prevent accidents.

At the bottom of the window are two buttons. The actions taken when the buttons are selected are described below.

Button Actions
Button Action
OK Sends the stoCancelAction command to the Storage Server, with the appropriate values, for processing. Also removes the Cancel action dialogue window from the display.
Cancel Does not send the stoCancelAction command, but does remove the Cancel action dialogue window from the display.
Help Does not send the stoRequestAction command and does not remove the dialogue window from the display. However, help information describing the dialogue will be displayed.
