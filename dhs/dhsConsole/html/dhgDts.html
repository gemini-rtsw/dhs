Data Server Window

The Data Server is responsible for all bulk data transfers with other Gemini systems. It is also responsible for controlling the data flow within DHS.

The Data Server window is displayed whenever the Data Server button (labeled "DTS") is selected on the main window of the Console. See the Subsystem Overview for more details.

The components of the Data Server window include:

  • A menubar at the top, which contains a number of menus. The menus and the menubar are described in more detail below.
  • Status information in the middle, which displays the running conditions of the Data Server.
  • At the very bottom of the window is the short help display. The short help message displays brief textual descriptions of the Console's components.

Menubar

The menubar has four menus:
Commands, Options, Help, and Quit,
which are described below.

Commands

This menu contains the list of commands that can be requested from the Data Server window, which the Data Server will process. The commands that can be selected include:
Debug, Simulation, Reset Health, Datasets, Reset, Initialize, Ping, and Test.

After the command has been chosen from the menu a dialogue window will appear (described in detail in the command descriptions). Most of the dialogue windows are "modal", which means none of the other windows can be manipulated while the dialogue window is active. Usually the dialogue confirms the command choice. If the command is "confirmed" then the command is sent only to the Data Server for processing.

The commands shown on the "Commands" menu are also available from the toolbar shown in the status section of the Data Server window.

Options Menu

Currently the only item is "Health Description Length". Choosing this item allows the operator to change the number of health description messages shown in the drop down list.

Note more items may be added to this menu in the future.

Help Menu

This menu contains two items: "About" and "Extended...". If "About" is selected a brief message describing DHS is displayed in a pop-up window. If "Extended..." is chosen then this HTML page is displayed in a Netscape web browser.

Quit Menu

This menu contains one item: "Close". When "Close" is chosen the Data Server window is removed from the display, but the Data Server is not shut down. See the Shutdown command for information on shutting down DHS.

Data Server Status

The middle section of the Data Server window contains the Data Server's status information. This includes the following status items:
state, health, debug level, simulation level, health description, and number of incomplete datasets.
The status items can be viewed only, they can not be changed from the Console.

Toolbar

Below the status information is a toolbar, or row of buttons. When one of these buttons is invoked a dialogue window is displayed, usually confirming that the command chosen is the desired command. If the command is "confirmed" then the command is sent only to the Data Server for processing. The commands that can be selected are:

Debug, Simulation, Reset Health, Datasets, Reset, Initialize, Ping, and Test.
These commands can also be issued from the Commands Menu.
