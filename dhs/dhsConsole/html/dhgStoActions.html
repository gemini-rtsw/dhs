Storage Server's Action Queue

The action queue contains all actions that are currently being processed or waiting to be processed by the Storage Server. Actions are performed on media requests. The Storage Server can process more than one action at a given time; the number of actions that can be processed is determined from the Storage Server's configuration file, dhsStorage.config.

An action is one of:

retrieve, queue, prepare, write, cleanup, or notify.

Viewing the Action Queue

The Storage Server's action queue is displayed in the Action window. This window is displayed when either the "Action" button is selected or when "Action" is chosen from the "Views" menu on the Storage Server window.

Changing the Action Queue

The action queue can not be changed directly. However, it will change as the result of requesting, stopping, and rolling back actions. These actions can be requested by selecting buttons on the Request Overview section of the Storage Server window.

The Action Window

 The Action window displays the Storage Server's action queue.

The short help information for this window is displayed on the Storage Server's window.

The action queue is displayed in a non-editable list that has scrollbars. Each row of the list describes a separate action. The following information is shown for each action:

  • Action. One of the following: retrieve, queue, prepare, write, cleanup, or notify.
  • Request Identifier. The associated request's unique, numerical identifier.
  • Optional Value. If a value was given to the optional parameter in the stoRequestAction command the value is displayed.

The actions are listed in a sorted order. Those that are being processed (active) are listed first and are followed by the actions that are waiting to be processed (inactive). The inactive actions are sorted based on their position. Those actions which will be processed first will appear closer to the top.

If the actions are active they appear green in colour and if they are inactive they are yellow in colour. The list of actions and their colours can be matched with the coloured buttons on the Storage Server window.

Two buttons appear at the bottom of the window: "OK" and "Help". The actions taken by the buttons, when selected are as follows:

Button Actions
Button Action
OK Removes the action window from the display.
Help Displays this help information.
