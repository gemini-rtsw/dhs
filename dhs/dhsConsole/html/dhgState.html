State

The state of DHS indicates the overall operational mode of DHS, and a subsystem's state indicates the subsystem's current operational mode. Given a particular state there is one or more other states that it could change to. The state transition diagram below indicates what changes or transitions are allowed.

The overall state of DHS is the state of the least functional DHS subsystem.

Viewing Overall DHS State

The overall state of DHS is displayed on the main window of the Console. The value appears beside the text "State:" on the main window.

Viewing Subsystem States

A subsystems state appears on the subsystem's window, beside the text "State:". Subsystem windows can be displayed by invoking the subsystem identifiers (buttons) on the main window of the Console. See Subsystem Overview for more information.

The subsystem's state can also be viewed quickly from the main window of the Console. The box to the right of each identifier contains the subsystem's state. See Subsystem Overview for more information.

Changing State Values

The state of DHS and the subsystems can not be changed directly. However, the state should change when a Reset, Initialize, or Test command is executed.

Expected Values

The expected values are listed in the table below in increasing level of functionality.
Expected State Values
Value Interpretation
SHUTTING DOWN The system is in the process of shutting down, or is shut down.
STARTING The system is being started.
INITIALIZING System is started but not running yet, "reset" or "init" command has been issued on the system.
TESTING The system is performing a self test as a result of a "test" sequence command being issued.
RUNNING The system is in its normal operating state, and it is ready to accept connections and commands from other systems.
