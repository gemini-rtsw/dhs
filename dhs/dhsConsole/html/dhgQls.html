Quick Look Server Window

This server is responsible for distributing data to the Quick Look Tools.

The Quick Look Server window is displayed whenever the Quick Look Server button (labeled QLS) is selected on the main window of the Console. See the Subsystem Overview for more details.

The components of the Quick Look Server window include:

  • A menubar at the top, which contains a number of menus. The menus and the menubar are described in more detail below.
  • Status information in the middle, which details the running conditions of the Quick Look Server.
  • At the very bottom of the window is the short help display. The short help message displays brief textual descriptions of the Console's components.

Menubar

The menubar has four menus:
Commands, Options, Help, and Quit,
which are described below.

Commands Menu

This menu contains the list of commands that can be sent from the Console to the Quick Look Server for processing. The commands that can be selected include:
Debug, Simulation, Reset Health, Reset, Initialize, Ping, and Test.

After the command has been chosen from the menu a dialogue window will appear (the dialogue windows are described in detail in the command descriptions). Most of the dialogue windows are "modal", which means none of the other windows can be selected while the dialogue window is active. Usually the dialogue confirms that the chosen command is indeed the one that was desired. If the command is "confirmed" then the command is sent only to the Quick Look Server for processing.

The commands shown on the "Commands" menu are also available from the toolbar shown in the status section of the Quick Look Server window.

Options Menu

Currently the only item is "Health Description Length". Choosing this item allows the operator to change the number of health description messages shown in the drop-down list.

Note more items may be added to this menu in the future.

Help Menu

This menu contains two items "About" and "Extended...". If "About" is selected a brief message describing DHS is displayed in a pop-up window. If "Extended..." is chosen then this HTML page is displayed in a Netscape web browser.

Quit Menu

This menu contains one item: "Close". When "Close" is chosen the Quick Look Server window is removed from the display. However, it does not shut down the Quick Look Server. See the Shutdown command for information on shutting down DHS.

Quick Look Server Status

The middle section of the Quick Look Server window contains the status information for the Quick Look Server. The status information describes the current running conditions of the Quick Look Server. The status items shown include:
state, health, health description, debug level, and simulation level.
The status items can be viewed only, they can not be changed from the Console.

Toolbar

Below the status information is a toolbar, or row of buttons. When these buttons are invoked a dialogue window is displayed, usually confirming that the command chosen is the one desired. If the command is "confirmed" then the command is sent only to the Quick Look Server for processing. The commands that can be selected are:

Debug, Simulation, Reset Health, Reset, Initialize, Ping, and Test.
These commands can also be issued from the Commands Menu.
