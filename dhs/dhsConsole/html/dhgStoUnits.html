Storage Server's Unit List

The Storage Server's Unit List contains all of the media units known to the Storage Server. A unit of media contains a number of files, data that have been grouped together in order to be written to a single CD, DVD, Mammoth Tape, or some other form of media. A media unit remains in the unit list from the time it is created ( queued) until it is destroyed (cleaned up).

Viewing the Unit List

The unit list is displayed in the Storage Server's Unit window. This window is displayed when either the "Units" button is selected or when "Units" is chosen from the "Views" menu on the Storage Server window.

Changing the Unit List

The unit list can not be changed directly. However, it will change as the result of requesting, stopping, and rolling back of queue, prepare, write, and cleanup actions. These requests can be made from the buttons on the Request Overview section of the Storage Server window.

The Unit Window

 The Unit window displays the Storage Server's unit list. The unit list is displayed in a scrollable, non-editable list. Each row of the list describes a separate unit. The following information is shown for each unit:

Name The name that has been given to the unit.
Request Identifier The associated requests unique, numerical identifier.
Size The number of Megabytes of data in the media unit.
Prepared? True if the unit has been prepared.
Number Written The number of media units that have been written so far.
Cleaned Up? True if the media unit as been cleaned up.

The list of units is displayed in a sorted order. First they are sorted based on the request identifiers with the lowest one appearing at the top. If two units have the same request number then their unit names are used to sort them. Those with lexicographically smaller names appear higher in the list.

Two buttons appear at the bottom of the window: "OK" and "Help". The actions taken by the buttons, when selected are as follows:

Button Actions
Button Action
OK Removes the Unit window from the display.
Help Displays this help information.
