Storage Server Requests

A request from the Storage Server's point of view is either an appeal to write data to media for the purposes of the Gemini Archive or for user transportable media.

Viewing Requests

An overview of the request information is displayed on the Storage Server's window. This overview displays most of the request information.

More detailed, textual information is shown in the Request window. This window displays all of the request information, including some details which are not available from the Storage Server window.

A Request window is displayed when the button containing the request's name on the Storage Server's window is selected.

Changing Request Information

Request information can not be changed directly. However, the information will change as the request gets processed. Thus, it changes indirectly when actions are requested, stopped, and/or rolled back, which can be done from the Request Overview section on the Storage Server's window.

Storage Server's Request Window

 The Request Window displays the status information for a given request. The information shown is updated when the status information changes.

Each bit of information, except for the name, is displayed in an non-editable box with an appropriate label. The name of the request is given at the top of the window as well as in the window's title. The information displayed includes the following:

  • Request Identifier.
    A numerical value which uniquely identifies a request.
  • Request name.
    The name of the request.
  • Media Type.
    The type of media that is to be written, such as CD, DVD, or tape.
  • Autoretrieve.
    The autoretrieve values indicates if the request is to be retrieved automatically.
  • Retrieval status
  • Queue status
  • Prepare status
  • Write status
  • Cleanup status
  • Notify status
Each request is displayed in a separate window, thus a request window can be open for each request listed on the Storage Server window. Each request is given a unique request identifier which can be used to uniquely identify a request.

Two buttons appear at the bottom of the window: "OK" and "Help". The actions taken by the buttons, when selected are as follows:

Button Actions
Button Action
OK Removes the Request window from the display.
Help Displays this help information.
