Dataset Display

The Data Server maintains a list of datasets that it is aware of. These datasets may reside in the of the Data Server's Permanent or Temporary storage areas. The Data Server is also aware of files at other locations, such as a particular magnetic disk. The dataset display window lists these datasets. It does not list the archived data.

Viewing the Dataset List

The Data Server's dataset list is shown in the dataset display window. This window is displayed when the "Datasets" command is selected on the Data Server's subsystem window

The Dataset Display Window

 The Dataset Display window is displayed from the Data Server's subsystem window.

The known datasets are displayed in a scrollable list. Each dataset is displayed on a separate line and its information is shown in four columns. The following information (columns) is given for each dataset:

  • File Name. The name of the file, its full path is not given.
  • Format. One of the following values: (F)ITS, or (R)aw.
  • Volume Name. The name of the volume where the file is located.
  • Size. The size of the file in kilobyes.

Note that the list of datasets is static! The list displayed is the list of datasets given by the last datasetInfo command that was issued from the Console. Thus, the list shown in this window may not be the same as the Data Server's list.

At the bottom of the window is a row of buttons. Two of these buttons (Header, and Delete) require a dataset to be selected before they are invoked. The actions taken by the buttons when they are selected are as follows:

Button Actions
Button Action
Header Executes dhsGet to retrieve the FITS header of the selected dataset. The FITS header is displayed in a separate window, the FITS Header window
Delete Asks the Data Server to issue a bdDelete command on the selected dataset. If this command is successful the dataset is removed from the list and if its FITS header was displayed then its FITS Header window will be removed from the display (destroyed).
Refresh Asks the Data Server to issue a datasetInfo command. The results of this command are displayed in the dataset display window the command was issued from. This button allows a user to display an up-to-date list in the dataset display window.
OK Removes the dataset display window from the display.
Help Displays this help information.

Viewing the FITS header of a dataset

The actions listed below are performed on the Dataset Display window.
  1. Select a dataset
  2. Select the "Header" button.

Deleting a dataset

The actions listed below are performed on the Dataset Display window.
  1. Select a dataset
  2. Select the "Delete" button.

Getting an up-to-date dataset list

The action listed below is performed on the Dataset Display window.
  1. Select the "refresh" button.
