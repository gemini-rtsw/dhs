DHS Resources

DHS resources include magnetic disks for creating and manipulating data and SYBASE database(s) for storing information.

Viewing Resource Information

An overview of resource information is provided on the main window of the Console.

More detailed information can be examined on the resource window. This window is is displayed when a resource identifier, on the main window, is selected.

Changing Resource Information

Resource information can not be changed directories. However, the resource usage will change as a result of DHS operations.

Also direct manipulation of the resources can cause changes. Direct manipulation includes things such as removing files from and copying file to a magnetic disk, as well as, inserting into or deleting from a database table.

Resource Window

The resource window is a simple window in that it does not contain a menubar or a short help window. Despite the lack of a short help window short help information is provided, but the help message appears in the Console's short help window instead. The short help message can be viewed by moving the mouse cursor over a particular component of the resource window.

The resource window displays all of the status information for a particular resource. Each status item is displayed in an uneditable box with an appropriate label. The name of the resource appears at the top of the window. The information shown is updated when the status information changes. The information displayed includes the following:

  • Full Name. For magnetic disks the fully specified path of the magnetic disk. For databases the SYBASE server and database name separated by a colon.
  • Type. Either magnetic disk or database.
  • Units. The units used to specify the maximum, used, and available values. An example would be kilobytes or megabytes.
  • Maximum. The total amount of resource that is available for use.
  • Used. The amount of resource that is currently being used.
  • Available. The amount of resource that is currently available for use.
  • Capacity. The percentage of resource that is being used.
Each resource is displayed in a separate window. The name at the top of the resource window can be used to differentiate the various resource windows.

Two buttons appear at the bottom of the window: "OK" and "Help". The actions taken by the buttons, when selected are as follows:
Button Actions
Button Action
OK Removes the Resource window from the display.
Help Displays this help information.
