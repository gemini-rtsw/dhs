Number of Incomplete Datasets

As its description indicates the value of this status item is the number of datasets that the Data Server views as incomplete. More precisely it is the number of datasets whose processing has not been completed by the Data Server. An example of an incomplete dataset is one whose "last chunk" has not been received by the Data Server.

Viewing the Number of Incomplete Datasets

The Number of Incomplete Datasets appears on the Data Server's subsystem window, beside the text "Number of Incomplete:". The Data Server subsystem window can be displayed by invoking the Data Server button (labeled "DTS") on the main window of the Console. See the Subsystem Overview for more information.

Changing the Number of Incomplete Datasets

This value is an internal value set by the Data Server. There is no way of setting the value directly from the Console. However, this value will be altered as a side effect of some of the Data Server commands. For example the Reset and Initialize commands will set the number of incomplete datasets to zero.
