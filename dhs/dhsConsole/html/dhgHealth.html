Health

The health of a subsystem indicates how well it is operating and the overall health of DHS is the health of the least healthy subsystem.

Viewing Overall DHS Health

The overall health of DHS appears on the main window of the Console, beside the text "Health:".

Viewing Subsystem Health

A subsystem's health appears on the particular subsystem's window, beside the text "Health:". Subsystem windows can be displayed by invoking subsystem identifiers (buttons) on the main window of the Console. See the Subsystem Overview for more information.

Also, there is a "health LED" on the main window of the Console for each subsystem. The LED appears to the left of subsystem's identifier. The colour of an LED indicates the health of the corresponding subsystem. The expected health values and their colours are shown below. See the Subsystem Overview for more information.

Changing the Subsystem Health

The health can be set to "GOOD" with the Reset Health command.

The subsystem healths can not be altered in any other way. However, they can change as a side effect of a reset or initialization.

Expected Values

 The expected health values and colours are listed in the table below in increasing severity.

Value Interpretation
GOOD (green) System is working well, there are no known problems.
WARNING (yellow) System is operating but has encountered some minor problems.
BAD (red) System is having severe problems and may not be able to operate.
Any other value (gray) System operating conditions are undetermined.

Viewing Resource Monitoring Health

There is a health LED beside each resource bar on the main window of the Console. The colour of the LED indicates how healthy the resource monitoring is for that resource. The expected values and colours are shown below. See the Resource Overview help pages for more information on resource monitoring.

Changing the Resource Health

Resource monitoring health can not be changed. However, it can change when the Status Server is reset or initialized.

Expected Values

 The expected health values and colours are listed in the table below in increasing severity.

Value Interpretation
GOOD (green) Resource monitoring is working well, there are no known problems.
BAD (red) System is having severe problems and may not be able to operate.
