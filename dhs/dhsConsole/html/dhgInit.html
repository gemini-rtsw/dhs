Initialize Command

This command will cause configuration files to be re-read and DHS subsystems(s) will be reset. This command can be performed on an individual subsystem or on the entire DHS from the Console.

WARNING data will be lost during an initialize command, do not initialize the DHS unless it is absolutely necessary.

If the Status Server is initialized the Console will no longer receive the changes in status information. The Console should be quit and restarted to remedy this problem.

Viewing affected Status information

During an init command the state and health of the affected subsystems will change. The debug level and simulate levels of the affected subsystems may change. As a result of the changes in the subsystem state, health, debug level, and simulate levels the overall DHS health, state, debug level and simulate level will also change.

Some of the status records affected by the initialize command are:

state, health, debug level, and simulate level.

The Init Dialogue Window

 The Init Dialogue is displayed when the init command has been selected on the main window of the Console or from a subsystem window. This window is "modal", which means that all of the other windows are disabled while this window is viewable.

The dialogue displays a prompt, which indicates which subsystem(s) will be initialized and asks if initialization should proceed.

At the bottom of the dialogue are two buttons which can be selected. The buttons and their actions are described in the table below.

Button Actions
Button Action
OK Requests DHS to init the desired subsystem(s), and removes the init dialogue window from the display.
Cancel Does not request the init command, cancels it, and removes the init dialogue window from the display.

Initialize the entire DHS

  1. Display the init dialogue window, described above
    • From the "Commands" menu:
      Display the "Commands" menu and select "Initialize" from the menu
    • From the Toolbar:
      Below the status information is a row of buttons. Select "Initialize" from this row of buttons.
  2. Select the appropriate button at the bottom of the window. The actions taken by each button are described above.

Initialize a Subsystem

  1. Display the Subsystem Window:
    Select the desired subsystem's button on the main window of the Console
  2. Display the init dialogue window, described above
    • From the "Commands" menu:
      Display the "Commands" menu and select "Initialize" from the menu
    • From the Toolbar:
      Below the status information is a row of buttons. Select "Initialize" from this row of buttons.
  3. Select the appropriate button at the bottom of the window. The actions taken by each button are described above.
