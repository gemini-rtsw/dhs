Debug Command

This command sets the debug level of one or more of the DHS subsystems. Setting the debug level for the entire DHS causes sets the debug level for each DHS subsystems.

The debug level controls the amount of detail provided in the DHS log message, which is displayed on the Console. The default value is the value given to the -debug command-line option, or "NONE" if the -debug option was not used.

Viewing the Debug Level

The current debug level can be obtained from the debug level indicators.

The Debug Level Command Window

The Debug Level Command window can be displayed from the main window of the Console or from a subsystem window, as described below.

A separate debug level window can be displayed for each subsystem. The title given on the window indicates which subsystem the window is associated with, or if it is associated with the entire DHS system. The debug level command affects only the subsystem the window is associated with.

The Debug windows have a fixed set of choices: NONE, MIN, and FULL, described on the Debug Level indicator help page. This list of choices appears on the debug level menu. The debug level menu is displayed when the button beside the text "Selected Debug Level" is selected. Once the menu is displayed, select the desired debug level, and the menu will disappear but the selected value will now appear on the button. Note that debug level has not changed yet! It will change when the "OK" or "Apply" button is selected.

The current debug level is displayed in an uneditable box beside the text "Current Debug Level:".

At the bottom of the window is a row of buttons. The actions taken by the buttons when they are selected are as follows:

Button Actions
Button Action
OK Sends a debugLevel command to DHS, with the selected debug level. Removes the debug level command window from the display.
Apply Sends a debugLevel command to DHS, with the selected debug level. The debug level command window is NOT removed from the display.
Cancel Does not send a debugLevel command to DHS but, removes the debug level command window from the display.
Help Displays this help information.

Changing Overall DHS Debug Level

  1. Display the Debug Level Command Window:
    • From the "Commands" menu:
      Display the "Commands" menu and select "Debug" from the menu
    • From the Toolbar:
      Below the status information is a row of buttons. Select "Debug" from this row of buttons.
  2. Select the desired Debug Level:
    1. Display the Choice List:
      Select the button beside the text "Selected Debug Level"
    2. Select a debug level from the pop up menu. After a choice is made the list of choices is removed from the display and the selected value is shown. The debug level does not change until either the "OK" or the "Apply" button is selected.
  3. Select the appropriate button at the bottom of the window. The actions taken by each button are described above.

Changing Subsystem Debug Levels

  1. Display the Subsystem Window:
    Select the desired subsystem's button on the main window of the Console
  2. Display the Debug Level Command Window:
    • From the "Commands" menu:
      Display the "Commands" menu and select "Debug" from the menu
    • From the Toolbar:
      Below the status information is a row of buttons. Select "Debug" from this row of buttons.
  3. Select the desired Debug Level:
    1. Display the Choice List:
      Select the button beside the text "Selected Debug Level"
    2. Select a debug level from the pop up menu. After a choice is made the list of choices is removed from the display and the selected value is shown. The debug level does not change until either the "OK" or the "Apply" button is selected.
  4. Select the appropriate button at the bottom of the window. The actions taken by each button are described above.
