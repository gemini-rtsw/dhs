Health Description

The health description is a textual message containing a describing the DHS subsystem's health. The Subsystem's health description is changed whenever its health changes to something other than GOOD.

Viewing the Health Descriptions

The most recent health description is displayed in a box beside the text "Health Description:" on the subsystem windows. See Subsystem Overview on displaying subsystem windows.

A log of the health descriptions is kept. This log can be viewed by invoking the button which appears beside the health description.

Changing the Health Description Length

 To change the number of messages stored in the "log" do the following:
  1. Select the "Options" menu: either press the ALT and O keys simultaneously OR press mouse button 1 when the cursor is over the Options menu on the menubar on the subsystem window.
  2. Select "Health Description Length": either press the H key or press mouse button 1 when it is over the text "Health Description Length". A dialogue box should appear shortly.
  3. Enter the desired length: enter a positive integer value in the dialogue box that was displayed.
  4. Select one of the buttons: press mouse button 1 when cursor is over the desired button. The following actions are taken by the buttons:

Button Actions
Button Action
OK Changes the number of messages kept to the value given, if it is valid. It also removes the dialogue window from the display.
Cancel Does not change the number of messages stored but does remove the input dialogue from the display.
