Log Message

This indicator displays the DHS history logging message. This is a history of the commands executed by DHS, errors reported by DHS, and the status of the system.

Viewing the Log Messages

The most recent log message is displayed in a box where the text "Log Message:" appears on the main window of the Console. Because this message can change very rapidly at times, so rapidly it is nearly impossible to read the message, a "log" of messages is kept. The log can be viewed by invoking the button which appears beside the log message.

Changing the amount of Information Logged

The amount of information reported depends on the Debug Level of the various DHS subsystems. The greater the debug level the larger the quantity of information being logged. The debug level can be altered with the Debug Level Command.

Changing the Log Length

 To change the number of log messages retained in the "log" do the following:
  1. Select the "Options" menu: either press the ALT and O keys simultaneously OR press mouse button 1 when the cursor is over the Options menu on the menubar on the Console.
  2. Select "Log Length": either press the L key or press mouse button 1 when it is over the text "Log Length" A dialogue box should appear shortly.
  3. Enter the desired length: enter a positive integer value in the dialogue box that was displayed.
  4. Select one of the buttons: press mouse button 1; when the cursor is over the desired button. The following actions are taken by the buttons:

Button Actions
Button Action
OK Changes the number of messages kept to the value given, if it is valid. It also removes the dialogue window from the display.
Cancel Does not change the number of messages stored but does remove the input dialogue from the display.
