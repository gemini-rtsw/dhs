Ping Command

This command checks to see if a subsystem(s) is accepting commands. Note that just because a subsystem is accepting commands it does not mean that the subsystem is handling the commands. This command can be performed on an individual subsystem or on the entire DHS.

A ping command does not alter any of the status information displayed except the Log Message and possibly the subsystem's Health Description.

The Ping Dialogue Window

The Ping Dialogue is displayed when the ping command has been selected on the main window of the Console or from a subsystem window. This window is "modal", which means that all other windows are disabled while this window is viewable.

The dialogue displays a prompt, which indicates which subsystem(s) will receive the ping command and asks if the ping command should proceed.

At the bottom of the dialogue are two buttons which can be selected. The buttons and their actions are described in the table below.

Button Actions
Button Action
OK Sends the ping command to DHS and removes the ping dialogue window from the display.
Cancel Does not send the ping command, but and removes the ping dialogue window from the display.

Ping all DHS Subsystems

  1. Display the ping dialogue window, described above
    • From the "Commands" menu:
      Display the "Commands" menu and select "Ping" from the menu
    • From the Toolbar:
      Below the status information is a row of buttons. Select "Ping" from this row of buttons.
  2. Select the appropriate button at the bottom of the window. The actions taken by each button are described above.

Ping a Subsystem

  1. Display the Subsystem Window:
    Select the desired subsystem's button on the main window of the Console
  2. Display the ping dialogue window, described above
    • From the "Commands" menu:
      Display the "Commands" menu and select "Ping" from the menu
    • From the Toolbar:
      Below the status information is a row of buttons. Select "Ping" from this row of buttons.
  3. Select the appropriate button at the bottom of the window. The actions taken by each button are described above.
