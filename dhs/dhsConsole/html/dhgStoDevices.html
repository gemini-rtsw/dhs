Storage Server Devices

The Storage Server's is responsible for the creation of archive and transportable user media. This media maybe a tape, CD-ROM, or DVD media. In order to write this media the storage server requires a repository of devices.

Each unit of media will book a logical device to write the media. A logical device is a name that has been given to one or more devices which have the same media type. For example, the name "cd1" may refer to a single CD-writer and the name "cdPair1" may refer to two CD-writers.

The number of media written on each device will depend on the total number of copies that need to be written. For example, if there are two devices associated with the logical device used but three copies to make then one device will create two media, while the other device will write create only one.

Viewing the Devices

The devices are displayed in the Storage Server's Device window. This window is displayed when either the "Devices" button is selected or when "Devices" is chosen from the Views menu on the Storage Server window.

Changing the Device Information

The Device information can not be changed directly. However, it will change as the result of requesting, stopping, and rolling back of a write command. These write command can be initiated by selecting the write buttons on the Request Overview section of the Storage Server window.

The Device Window

 The Device window displays the devices that are available to the Storage Server. The devices are displayed in a scrollable, non-editable list. Each row of the list is a separate device area. The following information is shown for each device:

Logical Name The name that has been given to a single and/or multiple devices. This name may appear in three colours:
  • green. The device can safely be used.
  • yellow. The device is currently in use.
  • red. the devices is not available for use.
Media Type The type of media that are written by the logical device.
Capacity The amount of data, in Megabytes, that can be stored on one media produced by the logical device.
Number of Devices The number of physical devices that are associated with the logical device.
Request ID The unique request identifier that currently has the device booked.
Unit Name The name of the media unit which currently has the device booked.

Two buttons appear at the bottom of the window: "OK" and "Help". The actions taken by the buttons, when selected are as follows:

Button Actions
Button Action
OK Removes the Stage window from the display.
Help Displays this help information.
