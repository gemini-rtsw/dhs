Reset Command

The reset command will cause all ongoing activities to be stopped, and any configuration information loaded from other Gemini systems will be lost. This command can be performed on an individual subsystem or on the entire DHS.

WARNING data will be lost during a reset command, do not reset the DHS unless it is absolutely necessary.

After the Status Server is reset it is unable to talk to the Console. The Console should be quit and restarted to guarantee it is displaying correct information.

Viewing affected Status information

During a reset command the state and health of the affected subsystems will change. The debug level and simulate levels of the affected subsystems may change. As a result of the changes in the subsystem state, health, debug level, and simulate levels the overall DHS health, state, debug level and simulate level will also change.

Some of the status records affected by a reset command are:

state, health, debug level, and simulate level.

The Reset Dialogue Window

 The Reset Dialogue is displayed when the reset command has been selected on the main window of the Console or from a subsystem window. This window is "modal", which means that all other windows are disabled while this window is viewable.

The reset dialogue displays a prompt, which indicates which subsystem(s) will be reset and asks if the reset command should proceed.

At the bottom of the dialogue are two buttons which can be selected. The buttons and their actions are described in the table below.

Button Actions
Button Action
OK Sends the reset command to DHS, and removes the reset dialogue window from the display.
Cancel Does not send the reset command, but removes the reset dialogue window from the display.

Reset the entire DHS

  1. Display the reset dialogue window, described above
    • From the "Commands" menu:
      Display the "Commands" menu and select "Reset" from the menu
    • From the Toolbar:
      Below the status information is a row of buttons. Select "Reset" from this row of buttons.
  2. Select the appropriate button at the bottom of the window. The actions taken by each button are described above.

Reset a Subsystem

  1. Display the Subsystem Window:
    Select the desired subsystem's button on the main window of the Console
  2. Display the reset dialogue window, described above
    • From the "Commands" menu:
      Display the "Commands" menu and select "Reset" from the menu
    • From the Toolbar:
      Below the status information is a row of buttons. Select "Reset" from this row of buttons.
  3. Select the appropriate button at the bottom of the window. The actions taken by each button are described above.
