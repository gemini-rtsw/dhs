Reset Health Command

This command sets the overall health of DHS or the health of a subsystems to GOOD. In order to set the overall health of DHS to GOOD all of the subsystem's health are set to GOOD.

The health of DHS indicates how well DHS is running, similarly the health of a subsystem indicates how well the subsystem is running. See the health help pages for more details.

Viewing the Health

The current health of DHS and the health of subsystem can be viewed by the health indicators described in the health help pages.

The Reset Health Dialogue Window

 The Reset Health Dialogue is displayed when the reset health command has been selected on the main window of the Console or from a subsystem window. This window is "modal", which means that all other windows are disabled while this window is viewable.

The dialogue displays a prompt, which indicates which subsystem(s) will have there health reset and asks if the resetting of health should proceed.

At the bottom of the dialogue are two buttons which can be selected. The buttons and their actions are described in the table below.

Button Actions
Button Action
OK Sends the resetHealth command to DHS and removes the reset health dialogue window from the display.
Cancel Does not send the resetHealth command, but removes the reset health dialogue window from the display.

Changing Overall DHS Health to GOOD

  1. Display the reset health dialogue window, described above
    • From the "Commands" menu:
      Display the "Commands" menu and select "Reset Health" from the menu
    • From the Toolbar:
      Below the status information is a row of buttons. Select "Reset Health" from this row of buttons.
  2. Select the appropriate button at the bottom of the window. The actions taken by each button are described above.

Changing Subsystem Health to GOOD

  1. Display the Subsystem Window:
    Select the desired subsystem's button on the main window of the Console
  2. Display the reset health dialogue window, described above
    • From the "Commands" menu:
      Display the "Commands" menu and select "Reset Health" from the menu
    • From the Toolbar:
      Below the status information is a row of buttons. Select "Reset Health" from this row of buttons.
  3. Select the appropriate button at the bottom of the window. The actions taken by each button are described above.
