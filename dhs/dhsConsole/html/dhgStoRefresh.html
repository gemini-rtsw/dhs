Refresh Command

The execution of the refresh command will cause the Storage Server to read the Archive Media database information. Executing this command synchronizes the Storage Server with the database. This command is nice to use when applications are run by hand.

This command can be performed on the Storage subsystem only.

Viewing affected Status information

As mentioned, during a refresh command the Archive Media database is re-read. A consequence of issuing this command is some or all of the media request information, displayed on the Storage Subsystem window, may be altered.

The Refresh Dialogue Window

 The Refresh Dialogue is displayed when the refresh command has been selected on the Storage Subsystem window. This window is "modal", which means that all other windows are disabled while this window is viewable.

The refresh dialogue displays a prompt, which asks if the refresh command should proceed.

At the bottom of the dialogue are two buttons which can be selected. The buttons and their actions are described in the table below.

Button Actions
Button Action
OK Sends the stoRefresh command to DHS, and removes the refresh dialogue window from the display.
Cancel Does not send the stoRefresh command, but removes the refresh dialogue window from the display.

Refresh the Storage Subsystem

  1. Display the Storage Subsystem Window:
    Select the desired button labeled "STO" on the main window of the Console
  2. Display the refresh dialogue window, described above
    • From the "Commands" menu:
      Display the "Commands" menu and select "Refresh" from the menu
    • From the Toolbar:
      Below the status information is a row of buttons. Select "Refresh" from this row of buttons.
  3. Select the appropriate button at the bottom of the window. The actions taken by each button are described above.
