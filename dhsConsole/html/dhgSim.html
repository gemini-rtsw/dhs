Simulation Level

The simulation level controls command processing. In simulate mode commands appear to be processed, but are not. When not in simulate mode all commands are processed. Note that simulation mode may operate differently for the Data Processing subsystem, which has not been developed yet.

The overall DHS simulation level is the highest simulation level set on any of the DHS subsystems. See the table below for the expected value.

Viewing Overall DHS Simulation Level

The simulation level for the entire DHS system appears on the main window, of the Console beside the text "Simulation Level:".

Viewing Subsystem Simulation Levels

The simulation level of a particular subsystem can be viewed on its subsystem window. It appears beside the text "Simulation Level:" Subsystem windows are displayed when the subsystem's identifier button is invoked on the main window of the Console. See the Subsystem Overview for more information.

Changing the Simulation Level

The simulation level can be set with the simulation level command.

The simulation level remains set until it is set to a new value, such as when DHS is initialized, reset, or shut down. The simulation level defaults to NONE on start-up or the value given by the optional -simulate command-line argument.

Expected Values

 All Gemini systems are expected to have four simulation levels. Although there are four simulation levels they behave like two. Two of the levels turn on the simulation mode while the other two turn it off (i.e. either a subsystem is in simulation mode or it is not). Note that simulation may operate differently for the Data Processing subsystem, which has not been developed yet. either the subsystems are in simulate mode or it is not. The exception to this is the Data Processing subsystems, which have not been implemented yet.

The simulation levels are listed in the table below in increasing order.

Expected Simulation Level Values
Level Affects on DHS
NONE Simulation is turned off.
VSM Operate in "Virtual System Mode", actions may be initiated and checked but the system does not perform further computations. This mode is not relevant to DHS so the simulation mode is set to NONE instead.
FAST Some internal computations may be performed, but response times are not realistic. This mode is not relevant to DHS so the simulation mode is set to FULL instead.
FULL Full simulation, events and responses are enabled. The subsystem responds to commands and simulates responses from lower subsystems.
