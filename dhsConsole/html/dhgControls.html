User-interface Controls

This page provides the details on how to manipulate the various widgets or components of the Console. The topics discussed include:
  • Accessing Help Information
  • Manipulating Menubars and Menus
  • Manipulating Log Messages and Heath Descriptions
  • Invoking Buttons
  • Text Entry
  • List Selection
  • Manipulating Scrollbars

Accessing Help Information

All help information is displayed in a Netscape browser; if no browser is running one will be started. See the Netscape help information on how to use the Netscape browser.

Help information is activated from menus and from buttons on the main window and the subsystem windows. Many of the pop up windows (dialogues) have help button. When these buttons are invoked the help information describing the window is displayed.

The main window and subsystem windows have a little box at the bottom for displaying "short help" messages. Short help messages are brief descriptions of the various bits and pieces that make up the Console. The message that is displayed describes the component under the cursor. To see the short help messages of a particular component move the cursor over the desired component. Note that windows that do not have a short help box display their messages in short help boxes on other windows.

Detailed help information describing a particular component of the Console can be accessed quickly with "context-sensitive" help. To display the help information of a particular component move the cursor over the component and press mouse button 3.

Manipulating Menubars and Menus

The main window and each of the subsystem windows contain a menubar at the top of the window. To select a menu from the menubar move the cursor over the desired menu and press mouse button 1. Menus can also be activated from the keyboard, by pressing the ALT key and the key of the underlined character in the menu's name. For example, to activate the "Commands" menu press the ALT and C keys simultaneously.

When selected, the menu is displayed with a number of choices. One of these items can be chosen or the menu can be removed without selecting any items. To make the menu disappear, press mouse button 1 when the cursor is not over the menu, or press the Escape key. To select one of the items either press mouse button 1 when the cursor is over the desired choice, or press the key of the underlined character. For example, to choose "Debug" from the "Commands" menu press the D key.

In addition, the arrow keys can be used to navigate the menu and the menubar. The up and down arrow keys move through the choices on the menu and the left and right arrow keys move between the menus. Once the desired selection is highlighted press the "Return" key to choose the item.

A menu can also be "torn off", removed from the menubar and is permanently displayed. This can be achieved by pressing mouse button 1 when it is over the dashed-line that appears at the top of the menu. Once the menu has been "torn off" it can be removed from the display and accessed from the menubar. (see window manager documentation on how to remove the window).

Manipulating Log Messages and Health Descriptions

The DHS log messages and health descriptions are displayed in a box with a scrollable, drop down list. The latest messages (descriptions) are displayed in the box. The drop down list displays the message (health description) log, gathered by the Console. The number of messages kept is fixed, but can be change from the "Options" menu.

To display the drop down list select the button beside the box. This list will continue to be displayed until one of the items in the list are selected or mouse button 1 is pressed when the cursor is over the button or the box.

Invoking Buttons

 Two types of buttons are used on the Console: push and radio.

Push Buttons

Push buttons, as their name suggests, when pushed cause an action to be initiated. Note that buttons whose text is gray in colour are not active, can not be invoked. Those that have black text are active.

Buttons appear at the bottom of dialogue windows and in toolbars. To invoke a particular button move the cursor over the button and press mouse button 1.

A second method of invoking buttons is to press the Return key. This will select the default button (has a ring around it).

Radio Buttons

Radio buttons are usually displayed in a group, where each button represents a "choice". They usually do not initiate any actions.

Radio buttons are used when a single item needs to be selected from a group of items. Only one radio button in the group can be selected at any given time. To select a radio button position the cursor over the button and press mouse button 1. Note that the previously selected radio button will be no longer be selected.

Pressing the space bar will also select a radio button if the radio button is highlighted when the space bar is pressed. To change the highlighted radio button press the TAB key.

Text Entry

On the Custom Stream Editor and the Configuration Editor there are places where text can be entered. Text can be entered in the sunken boxes, entry boxes, by typing when the box is selected. All normal printing characters are inserted where the insertion cursor is positioned.

Depending on the window manager configuration, the box can be selected by positioning the mouse over the box or by pressing mouse button 1 when the cursor is over the box. Note that the cursor should change to the "I" cursor when the box is selected.

To position the cursor at a given point in the text press mouse button 1 when the cursor is over the character just after the desired position. The left arrow and right arrow keys can also be used to move the cursor. To select a word "double-click" mouse button 1 and to select all of the text "triple-click" mouse button 1. On the other hand to select a given piece of the text position the cursor over the starting position hold mouse button 1 and move the cursor to the end of the piece, now release mouse button 1. Text can also be chosen by holding the shift key while moving the left arrow and right arrow keys. Note that if the mouse is "dragged" out of the box (left or right side) then the entry will automatically scroll to make more text visible, if there is more.

To insert the cursor at a given position without affecting the selection press mouse button 1 while holding down the Control key.

Other useful key controls include:

  • control and right arrow simultaneously moves the cursor to the right a word at a time.
  • control, shift, and right arrow simultaneously moves the cursor to the right a word at a time and "selects" text.
  • The home key moves the cursor to the beginning of the entry.
  • The home and shift key moves the cursor to the beginning of the entry, and selects the text.
  • The end key moves the cursor to the end of the entry.
  • The end and shift key moves the cursor to the end of the entry, and selects the text.
  • The delete or backspace key deletes the selection.
Further controls can be found in the Tcl/Tk entry man page, found in section n.

List Selection

Items can be selected from a list of items by pressing mouse button 1 when the cursor is over the desired items. Lists are displayed when the user is required to make a selection from a well-known set of items.

Manipulating Scrollbars

In general scrollbars are displayed only when necessary, when the text goes beyond the boundaries of the window. Scrollbars can appear on the main window as well as any of the subsystem windows, but normally should not be present. Scrollbars are also displayed anywhere a list of items is shown, such as the Storage Server's unit list.

The scrollbars themselves can be operated with the mouse. Pressing mouse button 1 when the cursor is over one of the arrows causes the scrollbar to move in the direction of the arrow. If the mouse button is held down the movement is repeated.

Pressing mouse button 1 when the cursor is over the "trough" causes the view to be shifted by one view. If the cursor is above the slider then it moves up and if the cursor is below the slider it is moved down, for a vertical scrollbar. The trough is the area of the scrollbar that is between the arrows.

Pressing mouse button 1 when it is over the slider and dragging it causes the view to be dragged with the slider. The slider is the portion of the scrollbar which moves.

Pressing mouse button 2 when it is over the trough sets the view to correspond to the mouse position. Pressing mouse button 2 when it is over the arrows causes the same action as mouse button 1. If mouse button 2 is pressed in the display area, where lists are displayed, the view is dragged while the button is held down.

If the Control key is down when mouse button 1 is pressed over an arrow or the trough the view is adjusted to the very top or the very bottom.
