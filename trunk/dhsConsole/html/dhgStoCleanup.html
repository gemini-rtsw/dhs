Cleanup Action

Cleanup is defined to be the "freeing" of a media staging directory, which is being used by a media unit. This process will remove all information contained in the staging directory. Once a media unit has been cleaned up another unit can be prepared, in the freed media staging directory.

Viewing Retrieval Information

There are three status records associated with retrieval. They are:
  • Cleanup Number.
    The number of media units (CDs) that can be removed from the staging directories.
  • Cleanup State.
    Indicates the current state of the cleanup action, expected values are given below.
  • Notify Value.
    "True" if the Data Server should be informed of the media requests completion.
All three status records are displayed on the Storage Server's window and on the Request window. The Request window displays each of the status records in a non-editable box. The subsystem window uses a combination of text and colours to portray this information.

Obtaining Further information

Further information describing the media units that can be cleaned up can be obtained by pressing the "cleanup" information button on the Storage Server window. This will display the Storage Server's Action Information window. Similarly, the list of media units ready for notification (have been cleaned up) can be obtained by pressing the "notify" information button.

Changing Cleanup Information

Cleanup information can not be changed directly. However, it does change when data is cleaned up, or during notification.

Cleanup information can also change during a reset or an initialize command.

Expected Cleanup State Values

 The expected cleanup state values are listed in the table below. Given any particular state there is one or more states the action can move to. The state transition diagram below depicts the allowed moves (transitions).

Expected Cleanup State Values
Value Interpretation
IDLE No processing is currently being performed on the data to be cleaned up.
REQUESTED A media unit is waiting to be cleaned up.
IN-PROGRESS A media unit is currently being cleaned up.
