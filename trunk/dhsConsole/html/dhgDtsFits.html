FITS Header Window

This window displays only the primary header of a dataset.

Viewing a FITS Header

The primary header of a dataset can be viewed in the FITS Header Window. The FITS Header window is displayed when the "Header" button on the Data Server's Dataset Window is selected.

Fits Header Window

 The FITS Header window is displayed from the Data Server's Dataset Window.

The primary header of a given dataset is displayed in a non-editable window with scrollbars. Each FITS keyword, its value, and related comments are displayed together on a single line.

At the bottom of the window is a row of buttons. The actions taken by the buttons, when selected, are:

Button Actions
Button Action
OK Removes the dataset display window from the display.
Help Displays this help information.
