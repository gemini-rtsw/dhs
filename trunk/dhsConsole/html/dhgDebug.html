Debug Level

The debug level is used to control the amount of detail provided by DHS debugging messages (log messages).

The debug level of DHS is the highest debugging level set on any of the DHS subsystems. See the table below for the expected values.

Viewing Overall DHS Debug Level

The debug level indicator for the entire DHS system appears on the main window of the dhsConsole, beside the text "Debug Level:" on the upper portion of the main window.

Viewing Subsystem Debug Levels

The debug level of a particular subsystem can be viewed on the subsystem window. It appears beside the text "Debug Level:". The subsystem window is displayed when the subsystems button is invoked from the main window of the Console. See Subsystem Overview for more information.

Changing the Debug Level

The debug level can be set with the debug level command.

The debug level remains set until it is set to a new value, such as when DHS is initialized, reset, or shut down. The debug level defaults to NONE on start-up or the value given by the optional -debug command-line argument.

Expected Values

 The debug levels are listed in the table below listed, in increasing order.

Expected Debug Level Values
Value Affect on DHS
NONE No debugging information is displayed.
MIN Moderate debugging information is displayed.
FULL Extreme debugging information is displayed.
