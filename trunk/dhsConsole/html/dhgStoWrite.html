Write Action

This action is defined to be the writing of a "prepared" media unit to a physical medium, such as a CD, DVD, or tape.

To write a CD, a prepared physical image is copied (written) onto the CDROM. The physical image will reside in one of the staging directories. When writing has completed, successfully, there will be a CDROM in the CD writer, which contains all of the data associated with the media unit.

The chosen CD authoring software is Elektroson GEAR. In the context of the CD-ROM, writing is defined as burning the GEAR physical volume onto a CD-Recordable disk.

Viewing Retrieval Information

There are three status records associated with retrieval. They are:
  • Write Number.
    The number of media units (CDs) available for writing.
  • Write State.
    Indicates the current state of the write action, expected values are given below.
  • Cleanup Number.
    The number of media units (CDs) that can be cleaned up, or the number of media units that have been fully written.
All three status records are displayed on the Storage Server's window and on the Request window. The request window displays each of the status records in a non-editable box. The subsystem window uses a combination of text and colours to portray this information.

Obtaining Further information

Further information describing the media units ready for writing can be obtained by pressing the "write" information button on the Storage Server window. This will display the Storage Server's Action Information window. Similarly, the list of media units that can be cleaned up (have been written) can be obtained by pressing the "cleanup" information button.

Changing Write Information

Write information can not be changed directly. However, it does change when media units are written, a write action is undone, a media unit is cleaned up, or when a cleanup action is undone.

Write information can also change during a reset or an initialize command.

Expected Write State Values

 The expected write state values are listed in the table below. Given any particular state there is one or more states the action can move to. The state transition diagram below depicts the allowed moves (transitions).

Expected Write State Values
Value Interpretation
ROLLBACK IN-PROGRESS The last write action that was processed is currently being "undone"
IDLE No processing is currently being performed on the data to be written.
REQUESTED A media unit is waiting to be written.
IN-PROGRESS A media unit is currently being written.
