Request Action Command

The request action initiates the processing of data retrieval, queuing of data, preparation of data, writing of data, cleaning up of data, and notification of data creation.

Once these commands have been initiated they may be stopped/cancelled by initiating the Cancel Action command. If the command has completed then this action can be undone, or rolled back, by initiating the Rollback command.

Initiating a Request Action Command

The Request Action command can be initiated by pressing on the Storage Server's window for the desired media requests. A number of detailed example of initiating a Request Action Command are given below. (Note: a forward button may be disabled, disallowing the action for the time being.)

Shortly after the button has been pressed a dialogue window will "pop-up". The dialogue window may ask the operator for input, different actions will require different input. Once the input has been entered and the "yes" button has been selected the command will be sent to the Storage Server for processing. A detailed description of the dialogue windows are given below.

Once the command has been received by the Storage Server the button that was pressed will turn yellow and/or green. Yellow indicating the command waiting to be processed, and green indicating the command is currently being processed. An entry will also be added to the Storage Server's action queue which can be viewed in the Action Window

When Preparing data and Writing data an xterm will pop-up. Third party software will be executed in this xterm. For example, for CD-Rs Elektroson's Gear software will be used. Please refer to third party's software documentation for more details. The operator may be prompted for input.

Viewing Affected Status Information

Media request information will be altered as the result of a Request Action command. Only the status records associated with the particular action and media request will be affected. The specific media request information that is altered is described in detail where the retrieve, queue, prepare, write, cleanup, and notify actions are described. All media request status records are displayed on the Storage Server's window in the "Request Overview" section. The information can also be found on the Request window for the affected request.

In addition to the media request information being altered the following items will change:

  • Action Queue. The action queue will grow by one every time an action is requested.
  • Unit List. The unit list will be altered for Queue, Prepare, Write and Cleanup actions.
  • Media Stage Directory List. The media staging directory information will change when a prepare and cleanup actions are requested.
  • Device List. The device list will change only when a write action is requested.

Request Action Dialogue Windows

 The Request Action dialogues are displayed when the appropriate forward button on the Storage Server window is selected. These windows are "modal", which means that all of the other windows are disabled while this window is viewable.

All of the dialogues prompt the operator for input, the exact input is described below. The media request name and requested action are displayed on the action so dialogue's for different actions can be differentiated. For all but the notify dialogue three buttons appear at the bottom of the dialogue windows. The actions taken by these three buttons are selected are described below. The notify dialogue buttons are described in the notify section.

Retrieve

The retrieve dialogue prompts the operator for the amount of data to be retrieved. The value entered in the box can be any decimal number between 0 and the amount of data that is available may be retrieved.

Queue

The queue dialogue prompts the operator for two different inputs: the number of media units to be queued, and whether queuing should be forced. To specify the number of units to queue enter an integer value between 0 and the number of possible units that may be queued in the box provided. To "force" queuing select the button to the left of the text "Forced". Similarly, select the button to the left of the text "Not Forced" to queue without forcing.

Prepare

The prepare dialogue prompts the operator for the number of media units to be prepared. To specify the number of media units enter an integer number between 0 and the number of possible units that may be prepared in the box on the dialogue window.

Write

The write dialogue prompts the operator for three different inputs: the number of media units to be written, which device(s) to use, and whether the booking of devices should be forced. To specify the number of units to write enter an integer value between 0 and the number of possible units that may be written in the box provided. To choose a specific device(s) first display the list of devices by selecting , then select the desired device from list. To "force" device booking select the button to the left of the text "Forced". Similarly, select the button to the left of the text "Not Forced" to not force the booking of devices.

Cleanup

The cleanup dialogue prompts the operator for the number of media units to be cleaned up. To specify the number of media units enter an integer number between 0 and the number of possible units that may be cleaned up in the box on the dialogue window.

Notify

The notify dialogue does not prompt the operator for any input. However, the notify window contains a "Yes" and "No" buttons, instead of the usual dialogue buttons described below. select the "Yes" button to issue the notification, and the "No" button to cancel the notification.

Button Actions
Button Action
OK Sends the stoRequestAction command to the Storage Server, with the appropriate values, for processing. Also removes the dialogue window from the display.
Cancel Does not send the stoRequestAction command, cancels it, and removes the dialogue window from the display.
Help Does not send the stoRequestAction command and does not remove the dialogue window from the display. However, help information describing the dialogues will be displayed.
