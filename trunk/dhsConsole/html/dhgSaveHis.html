Save History Log Command

The save history log Command takes the "active" history log and stores it in the DHS database, as well as the Gemini archive in a binary extension of a FITS file.

Viewing affected Status Information

If an errors occur while forwarding this command the health and Health Description of the Command Server may change. These values can be viewed on the Command Server's Window, and the main window of the DHS Console.

The Log message should also contain additional messages related to "Save History Log" command.

Finally, the health and health description of the History Server may change. These values can be viewed on History Server's Subsystem Window, and the main window of the DHS Console.

The Save History Log Dialogue Window

The Save History Log Dialogue is displayed when the save history log command has been selected on the History Server subsystem window. This window is "modal", which means that all other windows are disabled while this window is viewable.

The dialogue a prompt, which asks if the save history log command is to proceed.

At the bottom of the window are two buttons which can be selected. The buttons and their actions are described in the table below.

Button Actions
Button Action
OK sends the hisLogWrite command to DHS and removes the save history log dialogue window from the display.
Cancel Does not send the hisLogWrite command, but removes the save history log dialogue window from the display.

Save History Log a Subsystem

  1. Display the History Server subsystem window:
    Select the History Server button (labeled "HIS") on the main window of the Console
  2. Display the save history log dialogue window, described above
    • From the "Commands" menu:
      Display the "Commands" menu and select "Save History Log" from the menu
    • From the Toolbar:
      Below the status information is a row of buttons. Select "Save History Log" from this row of buttons.
  3. Select the appropriate button at the bottom of the window. The actions taken by each button are described above.
