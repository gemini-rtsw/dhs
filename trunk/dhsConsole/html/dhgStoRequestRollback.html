Request Rollback Command

The request rollback command is the "undo" of media request processing. Essentially, it rolls back to a previous state. The following actions can be rolled back:
queue, prepare, and write.

Once these commands have been initiated they can not be stopped. However, the roll back commands are added to the action queue. The Storage Server's window will be temporarily disabled until the Storage Server command has added the roll back command to it's action queue.

Once the roll back has completed continued processing of media request can be done with the initiation of actions.

Initiating a Rollback Action Command

The Rollback Action command can be initiated by pressing on the Storage Server's window for the desired media requests. A number of detailed examples of initiating a Rollback Action Command are given below. (Note: a reverse button may be disabled, disallowing the rollback operation temporarily.)

Shortly after the button has been pressed a dialogue window will "pop-up". The dialogue window will prompt the operator for the number of media units to roll back. The operator should enter an integer number between 0 and the number of possible units that may be rolled back in the box on the dialogue window. At the bottom of the dialogue are a number of buttons which are described in detail below.

Once the input has been entered and the "OK" button has been selected the command will be sent to the Storage Server for processing.

Once the command has been received by the Storage Server the button that was pressed will turn yellow and/or green. Yellow indicating the rollback command waiting to be processed, and green indicating the rollback command is currently being processed. An entry will also be added to the Storage Server's action queue which can be viewed in the Action Window

Button Actions
Button Action
OK Sends the stoRequestAction command to the Storage Server, with the appropriate values, for processing. Also removes the dialogue window from the display.
Cancel Does not send the stoRequestAction command, cancels it, and removes the dialogue window from the display.

Viewing Affected Status Information

Media request information will be altered as the result of a Rollback Action command. Only the status records associated with the particular rollback action and media request will be affected. The specific media request information that is altered is described in detail where the retrieve, queue, prepare, write, cleanup, and notify actions are described. All media request status records are displayed on the Storage Server's window in the "Request Overview" section. The information can also be found on the Request window for the affected request.

In addition to the media request information being altered the list of units will be changed during any of the roll backs, and the Storage Server media staging area information will change during the roll back of a prepare action.

Request Rollback Dialogue Windows

 The Request Rollback dialogue is displayed when one of the reverse buttons on the Storage Server window is selected. This window is "modal", which means that all other windows are disabled while this window is viewable.

A prompt is displayed, which asks if the Console should proceed with rolling back of the given action. The prompt states the name and media identifier of the media request.

At the bottom of the window are two buttons. The actions taken when the buttons are selected are described below.

Button Rollbacks
Button Rollback
OK Sends the stoRequestRollback command to the Storage Server, with the appropriate values, for processing. Also removes the request rollback dialogue window from the display.
Cancel Does not send the stoRequestRollback command, cancels it, and removes the request rollback dialogue window from the display.

Example Action Requests

 Below are several examples describing how to rollback queue, prepare, and write actions. All of these examples assume that the Storage Serve Window has been displayed byenter selecting the button labeled "STO" on the main window of the Console

Rolling Back A Queue Action
  1. Display the Rollback Queue Action Dialogue:
    Select under the column labeled Queue for the desired media request.
  2. Enter the needed input:
    Enter the number of units that are to be unqueued in the sunken box.
  3. Remove the Rollback Action Command window:
    Select the appropriate button at the bottom of the window. The actions taken by each button are described above.

Rolling Back A Prepare Action
  1. Display the Rollback Prepare Action Dialogue:
    Select under the column labeled Prepare for the desired media request.
  2. Enter the needed input:
    Enter the number of units that are to be unprepared in the sunken box.
  3. Remove the Rollback Action Command window:
    Select the appropriate button at the bottom of the window. The actions taken by each button are described above.

Requesting A Write Action
  1. Display the Rollback Write Action Dialogue:
    Select under the column labeled Write for the desired media request.
  2. Enter the needed input:
    Enter the number of units that are to be unwritten in the sunken box.
  3. Remove the Rollback Action Command window:
    Select the appropriate button at the bottom of the window. The actions taken by each button are described above.
