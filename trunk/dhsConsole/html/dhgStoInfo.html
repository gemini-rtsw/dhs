Storage Server Action Information

The stoInfo command is used to gather the action information of a particular request.

Viewing Action Information

The Action Information is displayed in the Action Window. This window is displayed when any of the value buttons is selected. The value buttons are displayed in the Request Overview section on the Storage Server's window.

Changing Action Information

Action Information can not be changed directly. However, the action information changes when actions are processed or rolled back. See the Storage Server's on-line help for information on how to do this.

Storage Server Action Information Window

 The Action Information Window displays the results of a stoInfo command. The results are displayed in an non-editable, scrollable window. Note that a large amount of data can be returned by the stoInfo command, which can take a substantial amount of time to gather.

The contents of the window depends on which value button, on the Storage Server window, was pressed. For instance, if the button containing the amount of data that can be retrieved was selected then a list of files ready for retrieval are shown. However, if the button displaying the number of media units ready for preparing is selected then information on each of the media units is given.

The information displayed in the window is static! The information does not change until the stoInfo command is re-issued.

A separate window is displayed for each value button. Therefore, more than one information window can be viewed at the same time. The window's title indicates what type of information is being displayed: Retrieve, Queue, Prepare, Write, Cleanup, or Notify. The type of information is also shown just above the table. The text displayed above the table states the media request name and identifier, which can be used to uniquely identify the various request windows and associate them with their value buttons.

Three buttons appear at the bottom of the window: "OK", "Refresh", and "Help". The actions taken by the buttons, when selected are as follows:

Button Actions
Button Action
OK Removes the Request window from the display.
Refresh Re-issues the stoInfo command to get more up-to-date information; the information is not automatically updated.
Help Displays this help information.
