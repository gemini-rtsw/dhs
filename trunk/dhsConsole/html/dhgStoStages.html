Storage Server's Stages

The Storage Server creates an image of the media (CD) on magnetic disk before it writes it to the actual medium (CD). In order to be guaranteed disk space, the Storage Server has its own staging areas. The Storage Server Stages then, are the various staging areas on magnetic disk used to store media images.

Each unit of media will have its own staging area when it is time for it to write. Staging areas are shared between the transportable media and the archive media.

Viewing the Stages

The staging areas are displayed in the Storage Server's Stage window. This window is displayed when either the "Stages" button is selected or when "Stages" is chosen from the "Views" menu on the Storage Server window.

Changing the Staging Information

The stage information can not be changed directly. However, it will change as the result of requesting, stopping, and rolling back of prepare, write, and cleanup actions. These requests can be made using the buttons on the Request Overview section of the Storage Server window.

The Stage Window

 The Stage window displays the Storage Server's staging areas. The stages are displayed in a scrollable, non-editable list. Each row of the list is a separate staging area. The following information is shown for each staging area:

Directory The name of the staging directory.
Name The name of the media unit which is currently occupying the staging directory.
Request Identifier The associated request's unique, numerical identifier.

Two buttons appear at the bottom of the window: "OK" and "Help". The actions taken by the buttons, when selected are as follows:

Button Actions
Button Action
OK Removes the Stage window from the display.
Help Displays this help information.
