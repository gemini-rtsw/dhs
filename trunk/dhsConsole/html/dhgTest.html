Test Command

The test command causes the DHS subsystem(s) to perform self-tests. These tests vary from subsystem to subsystem, but they will test the subsystems ability to perform their tasks.

Viewing affected Status Information

DHS status information will be updated to reflect any problems discovered. In particular test details should appear in the log message. If errors occur, the problems should be shown in the subsystem's health description. Also the Health of the subsystem(s) may change, depending on the results of the test. The state of all the subsystems being tested should be change to TESTING temporarily.

The status records affected by the test command are:

state, health, health description, and log message

The Test Dialogue Window

 The Test Dialogue is displayed when the test command has been selected on the main window of the Console or from a subsystem window. This window is "modal", which means that all other windows are disabled while this window is viewable.

The dialogue displays a prompt, which indicates which subsystem(s) will receive the test command and asks if the testing should proceed.

At the bottom of the dialogue are two buttons which can be selected. The buttons and their actions are described in the table below.

Button Actions
Button Action
OK Sends the test command to DHS and removes the test dialogue window from the display.
Cancel Does not send the test command but, removes the test dialogue window from the display.

Test all DHS Subsystems

  1. Display the Test Dialogue window, described above
    • From the "Commands" menu:
      Display the "Commands" menu and select "Test" from the menu
    • From the Toolbar:
      Below the status information is a row of buttons. Select "Test" from this row of buttons.
  2. Select the appropriate button at the bottom of the window. The actions taken by each button are described above.

Test a Subsystem

  1. Display the Subsystem Window:
    Select the desired subsystem's button on the main window of the Console
  2. Display the Test Level Command Window:
    • From the "Commands" menu:
      Display the "Commands" menu and select "Test" from the menu
    • From the Toolbar:
      Below the status information is a row of buttons. Select "Test" from this row of buttons.
  3. Select the appropriate button at the bottom of the window. The actions taken by each button are described above.
