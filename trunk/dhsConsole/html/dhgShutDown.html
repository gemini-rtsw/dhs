Shutdown Command

This command does a clean shutdown of the the entire DHS; all of the DHS subsystems are in turn asked to exit. The Console exits once it has been notified that the rest of DHS has exited.

Viewing affected Status information

During an exit command the state and health of all the subsystems will change.

The status records affected by an exit command; are:

state, and health.

The Shutdown Dialogue Window

 The Shutdown Dialogue is displayed when the shutdown command has been selected on the main window of the Console. This window is "modal", which means that all other windows are disabled while this window is viewable.

This window displays a prompt, which asks if the shutting down of DHS should proceed.

At the bottom of the dialogue are two buttons which can be selected. The buttons and their actions are described in the table below.

Button Actions
Button Action
OK Sends the exit command to DHS, and removes the shutdown dialogue window from the display.
Cancel Does not send the exit command, but removes the shutdown dialogue window from the display.

Shutting Down DHS

  1. Display the shutdown dialogue window, described above
    • From the "Commands" menu:
      Display the "Commands" menu and select "Shutdown" from the menu
    • From the Toolbar:
      Below the status information is a row of buttons. Select "Shutdown" from this row of buttons.
  2. Select the appropriate button at the bottom of the window. The actions taken by each button are described above.
