Flush Command

The only subsystem the flush command affects is the Status Server. The flush commands causes the Status Server to Flush all it's pending status information to EPICS and/or the Console

When the flush command is executed it can cause none, some, or all of the DHS status records to change value.

Viewing affected Status Information

The Status information is displayed on the main window, the subsystem window, and the resource windows. To find out more information on each of the subsystem windows see the Subsystem Overview.

The status items that may be affected by a flush command are:

debug, health, health description, log message, number of incomplete datasets, simulate, and state,
Also, any of the status items shown on the Resource Window and any of the status information specific to the Storage Server may be affected by the flush command.

The Flush Dialogue Window

 The Flush Dialogue is displayed when the flush command is been selected on the Status Server subsystem window. The dialogue window is "modal", which means that all of the other windows are disabled while this window is viewable.

A prompt is displayed on the dialogue, which asks if the flush command should be executed.

At the bottom of the window are two buttons which can be selected. The buttons and their actions are described in the table below.

Button Actions
Button Action
OK Sends the flush command to DHS and removes the flush dialogue window from the display.
Cancel Does not send the flush command, but removes the flush dialogue window from the display.

How to Flush DHS/Status Server

  1. Display the Subsystem Window:
    Select the button labeled "STA" on the main window of the Console
  2. Display the flush dialogue window, described above
    • From the "Commands" menu:
      Display the "Commands" menu and select "Flush" from the menu
    • From the Toolbar:
      Below the status information is a row of buttons. Select "Flush" from this row of buttons.
  3. Select the appropriate button at the bottom of the window. The actions taken by each button are described above
