Custom Stream Editor

This editor can be used to add or remove custom Quick Look streams from the list of subscribed streams. A custom stream is a stream that the Quick Look Server is not yet aware of. The initial list of custom streams is read from the Quick Look Tool's configuration file, dhsQlt.config. The custom stream editor can be used to change this list.

The components of the custom stream editor include:

  • A menubar at the top, which contains two menus. The menus and the menubar are described in more detail below.
  • A place to enter new streams.
  • A list of streams.
  • A row of buttons

Menubar

The menubar has two menus:
File, Help.
which are described below.

File

 When this "File" is selected from the menubar a menu is displayed with the following selections:
  • Load custom streams....
    Loads a set of streams from a file.
  • Save custom streams....
    Saves the current set of custom streams to a file.
Both of these display a file selection window to obtain the filename.

Help

 This menu provides access to the on-line help information. When this "Help" is selected from the menubar a menu is displayed with the following selections:
  • About QLT....
    Displays version information for the Quick Look Tool.
  • Help....
    Displays this page of on-line help information.

Adding New Streams

Just below the menubar is a box where the names of new streams can be entered. Type the new stream name into this box and press Return key to add the stream to the list.

Stream List

The main portion of this window contains the scrollable list of custom streams. This list can not be edited but is altered when new streams are added, deleted, or when the list of streams is reset.

To delete a stream the stream must be selected, and the delete button selected.

Buttons

At the bottom of the window is a row of buttons which perform the following functions, when selected:

Button Actions
Button Action
OK Updates the list of custom streams to be what is shown by sending the list to the Quick Look Server. Also removes the custom stream editor from the display.
Delete Removes the selected streams from the list.
Reset Restores the list of streams to the set of streams that were set when the window was displayed.
Cancel Remove the custom stream editor from the display without changing the list of custom streams.
