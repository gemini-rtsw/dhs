Quick Look Image Arithmetic Editor

The Quick Look image arithmetic editor allows the user to change the automatic image arithmetic that is applied to all incoming datasets. For example, all incoming datasets could be divided by a known calibration dataset. The arithmetic is performed before the data is displayed on the Quick Look Tool. The initial settings used for image arithmetic are read from the Quick Look Tool's configuration file.

NOTE:

  • The "operand" image must have the same dimensions as the incoming datasets, otherwise, the image arithmetic will not be performed. The operand image in the image which is being applied to the incoming image.
  • The operand image is retrieved from the DHS Data Server, thus it must be available to the Data Server.
  • There is an unavoidable penalty in display speed when image arithmetic is enabled.

The components of the Image Arithmetic Window include:

  • Operand entry.
  • Operator selection.
  • A row of buttons.

Operand Entry

The operand values specify which dataset and which frame within the dataset is to be used for the image arithmetic. The dataset and frame values to be used can be entered in the text entry boxes which appear at the top of the window. Type the desired dataset in the box labeled "Operand dataset". Similarly type the desired frame in the box labeled "Operand frame".

Note that these boxes must contain a value if an image arithmetic is to be performed on incoming data. If image arithmetic is turned off these values are ignored.

Operator Selection

The list of operators is fixed, more specifically it is one of:
  • none
  • addition
  • subtraction
  • multiplication
  • division
  • bad pixel mask.
This list of choices appears on the operator menu. The operator menu is displayed when the button below the label "Operator"is selected. Once the menu is displayed, select the desired operator. The operator menu will disappear at this point and the selected operator will now be displayed on the button. Note that the operator has not changed yet! It will change when the "OK" button is selected.

Selecting "none" turns off the DHS Quick Look automatic image arithmetic.

"addition", "subtraction", "multiplication", and "division" behave as expected. For example, the "addition" operator adds the values in the operand image to the incoming datasets.

The "bad pixel mask" operator sets all pixel values to "blank" wherever a pixel in the operand image has a value of "blank". The blank value is obtained from the "BLANK" keyword from the incoming dataset.

Buttons

At the bottom of the window is a row of buttons which perform the following functions, when selected:

Button Actions
Button Action
OK Updates the image operator and operand values to be the ones currently display on the Image Arithmetic window. Also removes the image arithmetic editor from the display.
Cancel Remove the image arithmetic editor from the display without altering the any of the operator or operand values..
Help Displays this page of on-line help information.
