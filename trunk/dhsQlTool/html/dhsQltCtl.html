Quick Look Control Panel

The Quick Look control panel is the component of the Quick Look Tool which allows users to choose (control) the data which the Quick Look Tool is aware of. It also has a few features which affect how the data is displayed. Other controls and features of the Quick Look Tool are provided by skycat, the underlying display tool used by the DHS Quick Look Tool.

The Quick Look control paned is displayed automatically whenever the Quick Look Tool is started up. Many of the default/initial values are read from the Quick Look Tool's configuration file, dhsQlt.config.

The components of the Quick Look control panel include:

  • A menubar at the top, which contains four menus. The menus and the menubar are described in more detail below.
  • A list of the current Streams Selected is shown.
  • A list of Available Frames is given.
  • At the very bottom of the window is the short help display. The short help message displays brief textual descriptions of the Console's components.

Menubar

The menubar has four menus:
Dataset, Stream, Configure, and Help.
which are described below.

Dataset

 This menu contains a number of items which operate on datasets. When "Dataset" is selected from the menubar a menu is displayed with the following selections:
  • AutoCut.
    If this check button is turned on, the Skycat cut levels (the mapping from image intensity to displayed colour) will be automatically re-set whenever the displayed image is updated. The displayed image is updated when there is a change in the data for the displayed image's data or when a new frame is displayed. When turned off, cut levels are only re-set when the user changes the cut levels with the Skycat controls. AutoCut improves the appearance of a displayed image, but may reduce performance, and in some cases the automatic changes to the image mapping can make evaluating the image quality difficult. The default value is read form the Quick Look Tool's configuration file.
  • Display Newest.
    If this check button is turned on, the Quick Look Tool will automatically the frame identified by the Quick Look Server as the "newest" frame. The display is updated whenever the data for the "newest" changes or when the newest frame changes to a different frame. When this check button is turned off, the display will be updated only if the currently displayed frame has changed. The "newest" frame will not be automatically displayed, however, the frames of the dataset containing the "newest" frame will be added to the frame list. It is possible to display the newest frame manually by selecting the frame identifier in the frame list. The default value is read form the Quick Look Tool's configuration file.
  • Auto Skip.
    If this check button is turned on, the Quick Look Tool will automatically skip image updates when it is unable to keep up with the data rate. The default value is read form the Quick Look Tool's configuration file.
  • Save Display.
    When this menu item is selected the currently displayed frame will be saved to the Gemini permanent store as a FITS file. The dataset name assigned to the saved image will be "datasetName-QL-nn", where datasetName is the dataset name of the currently displayed image, and nn is an index assigned by the Data Server. Note that only the currently displayed frame is saved, and will not include any of the other data associated with the dataset.
  • Display Dataset...
    When this menu item is selected a prompt dialogue will request the name of a dataset to display. Once a dataset name has been selected, the dataset is retrieved from the Data Server and displayed by the Quick Look Tool. When the data have been received, the last frame in the dataset will be displayed, and all available frames in the dataset will be listed in the frame list.
  • Image Arithmetic... When this menu item is selected the Image Arithmetic Editor will be displayed. This window allows the settings for image arithmetic to be altered; the initial values are read for the Quick Look Tool's configuration file.

Stream

 This menu controls the Quick Look streams that are displayed by the Quick Look Tool. When "Stream" is selected from the menubar a menu is displayed with the following selections:
  • Subscribe Streams.
    When this menu item is selected the Stream Selection window is displayed which allows the user to choose the data streams for display from the list published by the Quick Look Server.
  • Custom Streams.
    When this menu item is selected, the Custom Stream editor is displayed which allows the user to subscribe and unsubscribe from streams not yet known to the Quick Look Server.

Configure

 This menu allows the Quick Look Tool configuration information to be modified. When "Configure" is selected from the menubar a menu is displayed with the following selections:
  • Load Configuration.
    When this menu item is selected, a file selection widget is displayed. When a file is selected, the configuration information is read from that file.
  • Save Configuration.
    When this menu item is selected, a file selection widget is displayed. When a file is selected, the configuration information is written to that file. Note that if this function is used to over-write an existing configuration file any comments in the existing configuration file will be lost.
  • Change Configuration.
    When this menu item is selected, the configuration editor is displayed.

Help

 This menu provides access to the on-line help information. When this "Help" is selected from the menubar a menu is displayed with the following selections:
  • About QLT....
    Displays version information for the Quick Look Tool.
  • Help ....
    Displays this page of on-line help information.

Streams Selected

The selected streams are displayed on the left hand side of a "paned" window, which means that its size can be altered.

The list of selected streams appears as a passive, scrollable list. The list of quick look streams can be modified through the "Streams" menu. Data belonging to the selected streams, and no other data, will be displayed in the Quick Look Tool.

Note that if no streams are selected the Quick Look Tool will display data for all Quick Look Streams.

Available Frames

The available frames are displayed on the right hand side of a "paned" window, which means that its size can be altered.

This list displays the frames currently available for display. More precisely it contains all available frames associated with the "current" dataset and all available frames from the "newest" dataset. The "current" dataset is the dataset which the currently displayed frame belongs to and the "newest" dataset is the dataset which contains the frame identified by the Quick Look Server as the newest frame. Note that these two datasets will usually, but not always be the same. Datasets and frames will automatically be added to or removed from the list as the status of a dataset changes (i.e. if a dataset is no longer the displayed dataset or the newest dataset), or as new frames are added to a dataset.

Selecting a frame from this list causes it to be displayed.

The format of the frame names is "dataLabel.dataStream.index:frameId.frameId:frameName". (Note that there may be 0 or more frame identifiers.)
